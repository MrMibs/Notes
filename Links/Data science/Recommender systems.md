#datascience
## Definition
Recommender systems are models that **predict users likelyhood of interaction with a specific system** (as this is more measureable than liking).

## Core idea
Learn patterns from user–item interactions to estimate what a user is likely to like.

## Example
- Netflix recommending movies
- Spotify suggesting songs
- Amazon product recommendations

## Common approaches
- Collaborative filtering (user-based or item-based)
- Matrix factorization
- Content-based filtering
- Hybrid systems (combine multiple methods)

## Output type
- Ranked list of items or preference scores

## Key intuition
"If users similar to you liked X, you might also like X."

## When to use
- You want to personalize recommendations based on behavior data
