# Facet_wrap

| Argument         | Meaning                                                                      |
| ---------------- | ---------------------------------------------------------------------------- |
| `facets`         | The variable(s) to split by (usually `~var`)                                 |
| `nrow`           | Number of rows in the layout                                                 |
| `ncol`           | Number of columns in the layout                                              |
| `scales`         | Whether axes are fixed or free (`"fixed"`, `"free"`, `"free_x"`, `"free_y"`) |
| `shrink`         | Whether axes are adjusted to data range                                      |
| `as.table`       | Order of panels (like table layout)                                          |
| `dir`            | Direction (`"h"` or `"v"`)                                                   |
| `strip.position` | Where facet labels go (`"top"`, `"bottom"`, etc.)                            |
