#datascience
## Definition
Visualization quality measures how effectively a plot communicates information.

## Core dimensions
- Clarity: Is it easy to understand?
- Readability: Can details be interpreted correctly?
- Fidelity: Does it accurately represent the data?
- Messaging: Does it support the intended conclusion without distortion?

## Example
- A clean scatter plot with labeled axes (high quality)
- A 3D distorted chart hiding trends (low fidelity)

## Common issues
- Misleading scales
- Overplotting
- Cluttered visuals
- Poor color choices

## Key intuition
A good visualization does not just show data—it communicates it correctly and efficiently.

## When used
- Data analysis
- Reporting results
- Exploratory and explanatory data science
