## Definition
Estimator bias measures the **systematic difference between an estimator’s expected value and the true parameter**.

## Core idea
Does the estimator consistently overestimate or underestimate?

## Formal idea
Bias = E[estimate] − true value

## Asymptotic error
- Refers to behavior as sample size → infinity
- A good estimator often becomes unbiased or consistent in the limit

## Example
- Sample variance (with n vs n−1 correction)

## Key intuition
Bias is about **systematic error**, not random fluctuation.

## When used
- Evaluating statistical estimators
- Comparing models in inference settings
