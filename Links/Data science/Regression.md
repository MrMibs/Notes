## Definition
Regression is a type of supervised learning (or statistical modeling) used to **predict a continuous numerical value** from one or more input variables.

## Core idea
Learn a function that maps inputs → a real-valued output.

## Example
- Predict house price from:
  - size
  - location
  - number of rooms

## Common models
- Linear regression
- Polynomial regression
- Ridge / Lasso regression
- Random forest regression

## Output type
- Continuous (e.g., temperature, price, blood pressure)

## Key intuition
Regression fits a curve or surface that best describes the relationship between variables.

## When to use
- You want to estimate a number, not a category
