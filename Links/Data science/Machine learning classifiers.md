## Definition
Classifiers are models that **assign inputs to discrete categories (classes)**.

## Core idea
Learn decision boundaries that separate different classes in feature space.

## Example
- Email → spam or not spam
- Tumor → malignant or benign
- Image → cat, dog, or bird

## Common models
- Logistic regression (classification version)
- k-Nearest Neighbors (k-NN)
- Decision trees
- Random forests
- Support vector machines (SVM)
- Neural networks

## Output type
- Categorical (labels or probabilities)

## Key intuition
Instead of predicting a number, the model learns *which group something belongs to*.

## When to use
- You want to classify observations into categories
