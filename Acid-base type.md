# Acid–Base Theory Decision Map (Exam Version)

## Step 1: Are protons (H⁺) involved?

### YES → use **Brønsted–Lowry**

- Acid = H⁺ donor
    
- Base = H⁺ acceptor
    

**Typical cases:**

- Aqueous reactions
    
- Organic acids (carboxylic acids, NH₃, alcohols)
    
- Buffers, pH problems
    

Example:  
HCl + H₂O → H₃O⁺ + Cl⁻

---

## Step 2: No H⁺ transfer, but electron pairs involved?

### YES → use **Lewis theory (DEFAULT in inorganic chemistry)**

- Acid = electron pair acceptor
    
- Base = electron pair donor
    

**Typical cases:**

- Metal complexes (Cu²⁺, Ag⁺, Fe³⁺)
    
- Ligand binding (NH₃, H₂O, CN⁻)
    
- BCl₃, AlCl₃, BF₃
    
- Reaction intermediates (carbocations, electrophiles)
    

Example:  
Ag⁺ + NH₃ → \[Ag(NH₃)₂]⁺

---

## Step 3: Are you in molten oxides / solid-state oxide chemistry?

### YES → use **Lux–Flood**

- Acid = O²⁻ acceptor
    
- Base = O²⁻ donor
    

**Typical cases:**

- Metal oxides reacting
    
- Geology / metallurgy
    
- Slag formation (blast furnaces)
    

Example:  
Na₂O + P₂O₅ → Na₃PO₄

---

## Step 4: Are you in a non-aqueous solvent system (liquid SO₂, NH₃, etc.)?

### SOMETIMES → use **Solvent-system theory**

- Acid = increases characteristic cation of solvent
    
- Base = increases characteristic anion
    

**Typical cases:**

- Specialized inorganic solvents
    
- Older exam styles (less common today)
    

Example:  
2H₂SO₄ → H₃SO₄⁺ + HSO₄⁻

---

## Step 5: Is it high-level theoretical / general classification?

### ALWAYS SAFE OPTION → use **Lewis theory**

If unsure → pick Lewis.

---

# Ultra-fast exam shortcut

If you only remember ONE rule:

> **If electrons move → Lewis theory (almost always correct in inorganic chemistry).**  
> **If H⁺ moves → Brønsted.**  
> **If O²⁻ moves in solids → Lux–Flood.**

---

# Traps

- Metal complexes → **NOT Brønsted**, always Lewis
    
- Oxides in solution → usually still **Lewis unless molten**
    
- NO₃⁻ / SO₄²⁻ reactions in strong acids → **Lewis context, not Lux–Flood**
    
- Solvent-system theory → rarely required unless explicitly stated
