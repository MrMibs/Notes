#datascience
## Definition
Descriptive statistics are methods used to **summarize and describe the main features of a dataset** using numerical measures.

## Core idea
Reduce a large dataset into a few meaningful numbers.

## Common measures
- Mean
- Median
- Mode
- Variance
- Standard deviation
- Range
- Quartiles / percentiles

## Example
Instead of listing all exam scores:
- Mean = 72
- Standard deviation = 10
- Median = 74

## Output type
- Numerical summaries (and sometimes simple tables/plots)

## Key intuition
Descriptive statistics tell you **what the data looks like**, not why it is that way or what will happen next.

## When to use
- First step in data analysis
- Understanding dataset structure
- Reporting summaries
