An Ion trap is a [[Linear quadrupole (Q)]] but operated differently. Here we allow a band of masses to stay stable thereby as a bandpass.
![[Pasted image 20260528163602.png]]
This means we can store ions. We start by putting ions in the accumulator which allows us to accumulate ions as no DC signal is present cf. the graph above. When we have enough we put them into ion storage and maintain them within the center area (ion storage). When we want to work with them, we eject them through ion ejection. This means we remove kinetic energy before we send them to ion ejection. We can also kill some ions if we want because it is a quadrupole.
