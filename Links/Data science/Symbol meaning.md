#datascience

| Symbol | Meaning            | Reads as                       |                              |
| ------ | ------------------ | ------------------------------ | ---------------------------- |
| `!`    | NOT                | “negation / opposite”          |                              |
| `&`    | AND (element-wise) | “both conditions must be TRUE” |                              |
| \|     | OR                 | OR (element-wise)              | growth < 0 \| (or) hum > 100 |
| `==`   | equal to           | “is exactly equal”             |                              |
| `!=`   | not equal to       | “is not equal”                 |                              |
| `>=`   | greater or equal   |                                |                              |
| `<=`   | less or equal      |                                |                              |
| `>`    | greater than       |                                |                              |
| `<`    | less than          |                                |                              |
| `()`   | grouping           | controls order of logic        |                              |

|A|B|A \| B|
|---|---|---|
|TRUE|TRUE|TRUE|
|TRUE|FALSE|TRUE|
|FALSE|TRUE|TRUE|
|FALSE|FALSE|FALSE|
