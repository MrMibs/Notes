## Definition
Exploratory Data Analysis is the process of **investigating data to understand its structure, patterns, and quality before formal modeling**.

## Core idea
Use statistics and visualizations to explore data and generate hypotheses.

## Typical activities
- Plotting distributions (histograms, boxplots)
- Checking relationships (scatter plots, correlation)
- Detecting outliers
- Identifying missing data
- Summarizing variables

## Example
Before building a model to predict house prices:
- Check how price depends on size
- Look for skewed distributions
- Identify unusual data points

## Output type
- Insights, visualizations, and hypotheses (not final models)

## Key intuition
EDA is about **understanding the story in the data**, not making final predictions.

## When to use
- Early stage of any data analysis or machine learning project
- Before feature selection and modeling
