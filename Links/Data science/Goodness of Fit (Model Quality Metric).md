## Definition
Goodness of fit measures how well a model or distribution **matches the observed data**.

## Core idea
“How close are predicted/expected values to actual values?”

## Common tests
- Chi-squared test
- Kolmogorov–Smirnov (KS) test
- R^2

## Example
- Checking if observed counts match a theoretical distribution
- Comparing empirical vs theoretical cumulative distributions

## Key intuition
A good fit means the model describes the data structure well, but it does not guarantee predictive power.

## When used
- Distribution fitting
- Model validation for probabilistic models
