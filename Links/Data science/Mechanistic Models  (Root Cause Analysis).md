## Definition
Mechanistic models explain outcomes through **underlying processes, physical laws, or system behavior**, not just statistical correlation.

## Core idea
“What is the actual mechanism that produces the effect?”

## Approach
- Identify system components
- Trace causal chain step-by-step
- Validate via intervention or testing

## Example
Chemical reaction failure:
- incorrect temperature → reaction slows
- impurity → catalyst deactivation → low yield

## Root cause analysis
A structured method to move from:
symptom → intermediate causes → fundamental cause

## Key intuition
Focus is on *how* something happens, not just *whether* variables are related.

## Use cases
- Engineering diagnostics
- Medicine
- Forensics
- Troubleshooting systems
