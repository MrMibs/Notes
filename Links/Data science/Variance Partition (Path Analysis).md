## Definition
Variance partitioning decomposes the **variance of an outcome variable into contributions from different predictors** using a causal path structure.

## Core idea
“How much of the outcome is explained by each cause?”

## Method
- Uses regression or structural equation models
- Splits explained variance across pathways

## Example
Income variance explained by:
- Education
- Experience
- Ability

## Key intuition
It quantifies *relative causal contribution* in a structured model.

## Important note
Depends heavily on assumed causal structure—results change if the model structure changes.

## Use cases
- Social sciences
- Psychometrics
- Econometrics
