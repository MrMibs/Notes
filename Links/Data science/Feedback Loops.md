#datascience
## Definition
A feedback loop occurs when a model’s predictions influence the data it later learns from.

## Core idea
The model changes the environment it is trying to model.

## Example
- Recommendation system promotes popular items
- Users click those items more
- System learns they are even more popular
- Reinforces the same recommendations

## Why it is a problem
- Amplifies bias
- Reduces diversity
- Creates self-reinforcing predictions

## Key intuition
The model is not just observing the system—it is shaping it.

## When it matters
- Recommender systems
- Ranking algorithms
- Social media feeds
