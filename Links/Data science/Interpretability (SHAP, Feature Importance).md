## SHAP Values
## Meaning
Quantifies each feature’s contribution to a prediction.

## Key idea
Explains individual predictions using game theory.

---

## Feature Importance
## Meaning
Measures how much each feature contributes to model performance.

## Types
- impurity-based (tree models)
- permutation-based

## Key idea
Global measure of feature influence.

---

## Consistency
## Meaning
Whether feature importance rankings remain stable across models or samples.

## Key idea
Unstable importance → unreliable interpretation.
