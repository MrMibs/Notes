## Definition
Power analysis determines the **probability of correctly rejecting a false null hypothesis** and helps choose adequate sample size.

## Core idea
“How likely are we to detect an effect if it truly exists?”

## Key terms
- Power = 1 − β (β = false negative rate)
- Depends on:
  - sample size
  - effect size
  - significance level (α)
  - noise/variance

## Example
- Determining how many patients are needed to detect a drug effect

## Key intuition
Higher power means lower risk of missing real effects.

## When used
- Experimental design
- A/B testing
- Scientific studies
